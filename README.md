# MC Pack Studio

تطبيق ويندوز لتصميم ريسورس باكات ماينكرافت بسهولة، لكل الكلاينتات (Lunar, Badlion, Feather, LabyMod, Vanilla, CurseForge, Modrinth, Prism...).

## المميزات
- تعديل أي تكستر في اللعبة (سيوف، توتم، دروع، إليترا، بلوكات، واجهة، كل الملفات) برسام بكسلات أو باستيراد تصميمك (حتى HD)
- تكسترات ماينكرافت الأصلية 100% (تنحمّل تلقائياً من Mojang أو من ملفات الكلاينت)
- محرر سكن سهل: ارسم على الشخصية من 4 جهات
- تعديل الأصوات (MP3/WAV → OGG تلقائياً) مع قص وتحكم بالصوت
- سما مخصصة بـ 6 صور (OptiFine Custom Sky)
- فاير قصير، شيلد قصير، مصمم كروس هير، زجاج شفاف
- سمة ألوان للباك كامل
- مدير مودات: تفعيل/تعطيل/تعديل الصور والإعدادات داخل المودات
- تثبيت الباك في الكلاينت بضغطة (يدعم بروفايلات Lunar)
- نسخ احتياطية للباك، ثيمات للتطبيق
- يدعم من 1.8.9 إلى 1.21.11

## التشغيل من الكود
```bash
npm install
npm start
```

## بناء نسخة ويندوز
```bash
npx @electron/packager . "MC Pack Studio" --platform=win32 --arch=x64 --out=dist --asar --ignore='^/test' --ignore='^/dist' --ignore='^/release'
# ملف التثبيت: build/installer.nsi (NSIS)
```

> التطبيق ما يحتوي أي ملفات من ماينكرافت. غير تابع لـ Mojang أو Microsoft.
